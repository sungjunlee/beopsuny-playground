# 시나리오 8: 종합 법률 리서치 워크플로우

## 목표
실제 법률 문제를 조사할 때의 전체 워크플로우를 단계별로 학습합니다.

## ⚠️ 면책
이 시나리오는 기술 데모 목적이며, 실제 법률 자문이 아닙니다.

## 사용자 요구사항 (예시)

> "우리 회사가 개인정보를 수집·이용하려고 합니다.  
> 법적 요건이 무엇인지, 위반 시 제재는 어떻게 되는지,  
> 최근 규제 동향은 어떤지 종합적으로 조사해주세요."

## 📋 종합 리서치 체크리스트

### ✅ 1단계: 법령 확인 (법적 근거)
- [ ] 관련 법률 정확히 찾기
- [ ] 시행령/시행규칙 확인
- [ ] 시행일 확인
- [ ] 최근 개정 여부 확인

### ✅ 2단계: 행정규칙 확인 (실무 기준)
- [ ] 고시, 훈령, 예규 검색
- [ ] 구체적 기준, 절차, 서식 확인
- [ ] 과징금/과태료 부과기준

### ✅ 3단계: 정책 동향 파악 (집행 스탠스)
- [ ] 부처 보도자료 확인
- [ ] 최근 제재 사례
- [ ] 법령해석례
- [ ] 정책 기조 (강화/완화)

### ✅ 4단계: 판례 검색 (판단 기준)
- [ ] 관련 판례 키워드 검색
- [ ] 대법원 판례 우선
- [ ] 최신 판례 중심

### ✅ 5단계: 국회 동향 (법 개정 가능성)
- [ ] 계류 중인 개정안
- [ ] 최근 발의 법안
- [ ] 개정 방향

## 🔍 실전 워크플로우: 개인정보 수집·이용

### 1단계: 법령 확인

#### 1-1. 정확한 법령 검색

```bash
python scripts/fetch_law.py exact "개인정보보호법"
```

**예상 결과**:
- 개인정보 보호법 (법률 제19234호)
- 시행일: 2024.1.1
- 관련 법령: 개인정보 보호법 시행령, 시행규칙

#### 1-2. 법령 다운로드 및 핵심 조문 확인

```bash
# 시행령/시행규칙 포함 다운로드
python scripts/fetch_law.py fetch --name "개인정보보호법" --with-decree

# 핵심 조문 파싱 (제15조: 개인정보의 수집·이용)
python scripts/parse_law.py data/raw/개인정보보호법_*.xml --article 15
```

**핵심 조문**:
- 제15조: 개인정보 수집·이용의 동의 요건
- 제16조: 개인정보의 수집 제한
- 제34조의2: 과징금 (매출액의 3% 이하)

#### 1-3. 링크 생성

```bash
python scripts/gen_link.py law "개인정보보호법" --article 15
```

**결과**: https://www.law.go.kr/법령/개인정보보호법/제15조

#### 1-4. 최근 개정 확인

```bash
python scripts/fetch_law.py recent --days 90 | grep "개인정보"
```

### 2단계: 행정규칙 확인 ⭐

#### 2-1. 고시 검색 (구체적 기준)

```bash
# 과징금 부과기준
python scripts/fetch_law.py search "개인정보 보호법 위반 과징금 부과기준" --type admrul

# 안전성 확보조치
python scripts/fetch_law.py search "개인정보 안전성 확보조치" --type admrul

# 표준 개인정보 보호지침
python scripts/fetch_law.py search "표준 개인정보 보호지침" --type admrul
```

**예상 결과**:
1. "개인정보 보호법 위반에 대한 과징금 부과기준" (고시)
   - 위반 유형별 과징금 산정 공식
   - 가중/감경 사유
   
2. "개인정보의 안전성 확보조치 기준" (고시)
   - 암호화 기준
   - 접근통제
   - 개인정보 파기 방법

3. "표준 개인정보 보호지침" (고시)
   - 동의서 작성 방법
   - 개인정보 처리방침 게시

**왜 중요한가**:
- 법률: "동의를 받아야 한다" (원칙만)
- 행정규칙: "동의서에 포함해야 할 10가지 항목" (실무 기준)

### 3단계: 정책 집행 동향 파악 ⭐

#### 3-1. 개인정보보호위원회 보도자료

```bash
python scripts/fetch_policy.py rss pipc --keyword 과징금
python scripts/fetch_policy.py rss pipc --keyword 제재
```

**파악할 정보**:
- 최근 제재 규모 (과징금 100억 원 부과 등)
- 집중 단속 분야 (예: 마케팅 동의 획득 방법)
- 정책 기조 (단속 강화/완화)

#### 3-2. 법령해석례

```bash
python scripts/fetch_policy.py interpret "개인정보 동의"
python scripts/fetch_policy.py interpret "개인정보 수집"
```

**파악할 정보**:
- 법제처 유권해석
- "동의"의 구체적 요건
- "정보주체"의 범위

#### 3-3. 웹검색 (최신 동향)

**검색 쿼리**:
```
"개인정보보호위원회 제재" 2024 2025 2026
"개인정보 과징금" 최근
```

### 4단계: 판례 검색

```bash
# 개인정보 수집·이용 관련 판례
python scripts/fetch_law.py cases "개인정보 동의 없이 수집" --court 대법원

# 개인정보 유출 손해배상
python scripts/fetch_law.py cases "개인정보 유출 손해배상"

# 최근 판례
python scripts/fetch_law.py cases "개인정보 침해" --from 20240101
```

**예상 결과**:
- 대법원 2023. 5. 18. 선고 2022다12345 판결
  - 동의 없는 수집에 대한 손해배상 인정
- 대법원 2024. 3. 12. 선고 2023다56789 판결
  - 개인정보 유출 시 위자료 산정 기준

### 5단계: 국회 동향 (개정안)

## 📊 종합 분석 예시

### 법적 요건 정리

**1. 개인정보 수집·이용 동의 요건**

근거: 개인정보 보호법 제15조제1항

필수 고지 사항:
1. 개인정보의 수집·이용 목적
2. 수집하려는 개인정보의 항목
3. 개인정보의 보유 및 이용 기간
4. 동의를 거부할 권리가 있다는 사실 및 거부 시 불이익

출처: "표준 개인정보 보호지침" (개인정보보호위원회 고시)

**2. 제재 수준**

법령: 제34조의2 (과징금 매출액 3% 이하)

행정규칙: "개인정보 보호법 위반에 대한 과징금 부과기준"
- 동의 없는 수집: 기본 과징금 + 매출액 비율
- 위반 횟수에 따라 가중 (최대 2배)
- 자진 신고 시 감경 (50%)

최근 제재 사례:
- 2026-09-15: A사 100억 원 과징금 (마케팅 동의 허위 획득)
- 2026-08-20: B사 50억 원 과징금 (동의 없이 제3자 제공)

**3. 현재 정책 기조**

정책브리핑 분석:
- 2026년 3분기: 마케팅 동의 획득 방법 집중 점검
- 정책 방향: 단속 강화 ⚠️
- 과징금 규모: 전년 대비 150% 증가

판례 동향:
- 동의 없는 수집에 대한 손해배상 인정 증가
- 위자료 액수: 1인당 30만 원 ~ 100만 원

**4. 법 개정 동향**

국회 계류 의안:
- 제22대 국회: 개인정보보호법 일부개정법률안 (의안번호 2205704)
- 주요 내용: 과징금 상한 5%로 상향
- 진행 상황: 소관위원회 심사 중

## 📝 최종 보고서 템플릿

```markdown
# 개인정보 수집·이용 법률 검토 보고서

## 1. 법적 요건

### 1.1 근거 법령
- **개인정보 보호법 제15조** (시행 2024.1.1.)
- [링크](https://www.law.go.kr/법령/개인정보보호법/제15조)

### 1.2 필수 요건
1. 정보주체의 **동의** 필수
2. 동의 시 **4가지 사항 고지** 필수
   - 수집·이용 목적
   - 수집 항목
   - 보유·이용 기간
   - 거부 권리 및 불이익

### 1.3 구체적 기준 (행정규칙)
- "표준 개인정보 보호지침" (개인정보보호위원회 고시)
- 동의서 작성 방법, 개인정보 처리방침 게시 방법 명시

## 2. 제재 수준

### 2.1 법령상 제재
- **과징금**: 매출액의 3% 이하 (제34조의2)
- **형사처벌**: 5년 이하 징역 또는 5천만 원 이하 벌금 (제71조)

### 2.2 실제 부과 사례 (2026년)
- A사: 100억 원 (마케팅 동의 허위 획득)
- B사: 50억 원 (동의 없이 제3자 제공)

### 2.3 현재 집행 기조
- **⚠️ 단속 강화**: 2026년 3분기 집중 점검
- 과징금 규모: 전년 대비 150% 증가

## 3. 판례 동향
- 동의 없는 수집 → 손해배상 인정 증가
- 위자료: 1인당 30만 원 ~ 100만 원

## 4. 법 개정 동향
- 과징금 상한 5%로 상향 개정안 계류 중 (22대 국회)

## 5. 권고사항
1. 동의서 작성 시 표준 보호지침 준수 필수
2. 현재 단속 강화 기조 → 철저한 준수 권고
3. 개정안 통과 시 과징금 부담 증가 예상

---

⚠️ **참고**: 이 정보는 일반적인 법률 정보 제공 목적이며,
구체적인 법률 문제는 변호사와 상담하시기 바랍니다.
```
