# 시나리오 3: 행정규칙 검색 (실무 핵심) ⭐

## 목표
법률의 구체적 적용 기준인 행정규칙(고시, 훈령, 예규)을 검색하고 활용하는 방법을 학습합니다.

## ⚠️ 면책
이 시나리오는 기술 데모 목적이며, 실제 법률 자문이 아닙니다.

## 왜 행정규칙이 중요한가?

### 실무자 피드백
> "법률이 바뀌는 것도 중요하지만, 실제로 적용되는 부분은 **고시, 훈령, 예규**에서 정하는 경우가 많습니다."

### 법률 vs 행정규칙

| 구분 | 법률 | 행정규칙 |
|------|------|----------|
| **규정 범위** | 큰 틀, 원칙 | 구체적 기준, 절차, 서식 |
| **예시 (개인정보)** | "과징금을 부과할 수 있다" | "위반 유형별 과징금 산정표" |
| **예시 (건축)** | "에너지 절약 설계 의무" | "건물 용도별 단열재 기준" |
| **예시 (금융)** | "전산설비 안전성 확보" | "백업 주기, 암호화 알고리즘 명시" |

## 사용자 요구사항

> "개인정보보호법 위반 시 과징금이 얼마나 나올까요? 구체적인 기준이 궁금합니다."

## 워크플로우

### 1단계: 법률 조문 확인

**실행**:
```bash
python scripts/fetch_law.py exact "개인정보보호법"
```

**예상 결과**: 
- 법률 조문에서 "과징금을 부과할 수 있다"는 범위만 확인 가능
- 구체적인 산정 기준은 행정규칙에 위임

### 2단계: 관련 행정규칙 검색 ⭐

**API 키 필요**: ✅ `BEOPSUNY_OC_CODE`

**실행**:
```bash
python scripts/fetch_law.py search "개인정보 과징금 부과기준" --type admrul
```

**예상 출력**:
```
=== 행정규칙 검색 결과 ===

[1] 개인정보 보호법 위반에 대한 과징금 부과기준
  - 종류: 고시
  - 소관: 개인정보보호위원회
  - 시행: 2024.01.01.
  - 링크: https://www.law.go.kr/행정규칙/(...)

[2] 개인정보의 안전성 확보조치 기준
  - 종류: 고시
  - 소관: 개인정보보호위원회
  - 시행: 2023.09.15.

[3] 개인정보 영향평가에 관한 고시
  - 종류: 고시
  - 시행: 2024.01.01.
```

### 3단계: 행정규칙 다운로드

**실행**:
```bash
python scripts/fetch_law.py fetch --name "개인정보 보호법 위반에 대한 과징금 부과기준"
```

**예상 내용**:
- 위반 유형별 과징금 기본 금액
- 매출액 대비 비율 기준
- 가중/감경 사유
- 구체적 산정 공식

## 🔍 행정규칙 유형별 특징

### 고시 (告示)
- **목적**: 일반 국민에게 알리는 규범
- **효력**: 대외적 구속력
- **예시**: 과징금 부과기준, 인증기준, 안전기준
- **검색 키워드**: "부과기준", "인증", "기준"

### 훈령 (訓令)
- **목적**: 상급기관이 하급기관에 지시
- **효력**: 행정기관 내부
- **예시**: 업무처리지침, 운용지침
- **검색 키워드**: "지침", "운용"

### 예규 (例規)
- **목적**: 반복적 업무의 처리 기준
- **효력**: 행정기관 내부
- **예시**: 세무 사무처리규정, 등기 업무처리지침
- **검색 키워드**: "사무처리", "규정", "처리지침"

## ✅ 검증 체크리스트

- [ ] 법률 조문만으로 판단하지 않기
- [ ] 법률 → 시행령 → **행정규칙** 순서로 체계적 확인
- [ ] 구체적 기준, 절차, 서식은 행정규칙에서 찾기
- [ ] 행정규칙 시행일 확인 (법률보다 자주 개정됨)
- [ ] 소관 부처 확인 (금융위, 고용부, 복지부 등)

3. **감경 사유** (50% 이하로 감경)

   - 피해 구제 노력

- 개인정보보호법 제34조의2 → **"과징금을 부과할 수 있다"** (범위만 규정)
