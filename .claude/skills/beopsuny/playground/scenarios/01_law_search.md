# 시나리오 1: 법령 정확 검색

## 목표
정확한 법령명으로 법령을 검색하고, 관련 시행령/시행규칙을 파악하는 방법을 학습합니다.

## ⚠️ 면책
이 시나리오는 기술 데모 목적이며, 실제 법률 자문이 아닙니다.

## 사용자 요구사항

> "민법 제750조 불법행위에 대해 알려주세요. 시행일과 관련 판례도 함께 확인하고 싶습니다."

## 워크플로우

### 1단계: 정확한 법령 검색

**Why `exact` 명령?**
- `search "민법"` 사용 시 문제점:
  - "**민법**", "군**형법**", "**민사소송법**" 등 부분 일치 결과 과다
  - API가 부분 문자열 검색만 지원하기 때문
  
- `exact "민법"` 사용 시 장점:
  - 정확히 "민법"만 반환
  - 관련 시행령/시행규칙 자동 표시
  - 법령 ID를 인덱스에서 조회하여 직접 다운로드

**실행**:
```bash
python scripts/fetch_law.py exact "민법"
```

**예상 출력**:
```
=== 법령 검색 결과 ===

[1] 민법
  - 법령ID: 001706
  - 시행: 2024.01.31.
  - 공포: 2023.01.31.
  - 링크: https://www.law.go.kr/법령/민법

관련 법령:
  - 민사소송법 (시행령 없음)
  - 가족관계의 등록 등에 관한 규칙

법령 다운로드:
  python scripts/fetch_law.py fetch --id 001706
  python scripts/fetch_law.py fetch --name "민법"
```

### 2단계: 법령 다운로드

**API 키 필요**: ✅ `BEOPSUNY_OC_CODE`

**실행**:
```bash
python scripts/fetch_law.py fetch --name "민법"
```

**예상 동작**:
1. `data/raw/민법_001706.xml` 파일 생성
2. XML 파일에 전체 법령 조문 포함
3. 메타데이터 (시행일, 공포일, 개정 연혁) 포함

**Skip 조건**:
- API 키 없으면: "OC code is required. Get it from https://open.law.go.kr"
- 해외 IP 차단 시: 프록시 설정 안내 (docs/PROXY_SETUP.md)

### 3단계: 특정 조문 파싱

**API 키 필요**: ❌ (로컬 파일 처리)

**실행**:
```bash
python scripts/parse_law.py data/raw/민법_001706.xml --article 750
```

**예상 출력**:
```markdown
## 민법 제750조 (불법행위의 내용)

> 고의 또는 과실로 인한 위법행위로 타인에게 손해를 가한 자는 그 손해를 배상할 책임이 있다.

- **시행일**: 2024. 1. 31.
- **링크**: https://www.law.go.kr/법령/민법/제750조

### 연혁
- 1958. 2. 22. 제정
- (개정 없음)
```

### 4단계: 링크 생성 및 검증

**API 키 필요**: ❌ (로컬 로직)

**실행**:
```bash
python scripts/gen_link.py law "민법" --article 750
```

**예상 출력**:
```
법령 링크: https://www.law.go.kr/법령/민법/제750조

이 링크를 브라우저에서 열어 조문을 확인할 수 있습니다.
```

**검증 방법**:
1. 브라우저에서 링크 열기
2. 국가법령정보센터에서 해당 조문 표시 확인
3. 조문 내용이 파싱 결과와 일치하는지 확인

### 5단계: 관련 판례 검색

**API 키 필요**: ✅ `BEOPSUNY_OC_CODE`

**실행**:
```bash
python scripts/fetch_law.py cases "민법 750조 불법행위 손해배상" --court 대법원
```

**예상 출력**:
```
=== 판례 검색 결과 ===

[1] 대법원 2023. 5. 18. 선고 2022다12345 판결
  - 요지: 불법행위로 인한 손해배상청구권의 소멸시효
  - 링크: https://www.law.go.kr/판례/(2022다12345)

[2] 대법원 2022. 3. 11. 선고 2021다98765 판결
  - 요지: 과실 인정 요건
  - 링크: https://www.law.go.kr/판례/(2021다98765)
```

## 🎯 핵심 학습 포인트

### 1. `exact` vs `search` 차이
| 명령 | 검색 방식 | 사용 시기 |
|------|----------|----------|
| `exact` | 정확히 일치하는 법령만 | 법령명을 정확히 알 때 (예: "민법", "상법") |
| `search` | 부분 일치 (키워드 포함) | 관련 법령을 넓게 찾을 때 (예: "개인정보") |

### 2. 시행일 확인의 중요성
- 개정 법령이 공포되었지만 아직 미시행인 경우 주의
- 미시행 법령은 `⚠️ 미시행 (2026.1.1. 시행 예정)` 형태로 표시 필요
- `recent` 명령으로 최근 개정 여부 확인 권장

### 3. 인용 형식
- **올바른 인용**: "민법 제750조 (시행 2024.1.31.)"
- **링크 포함**: https://www.law.go.kr/법령/민법/제750조
- **판례 인용**: "대법원 2023. 5. 18. 선고 2022다12345 판결"
